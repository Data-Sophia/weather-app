# Weather App

A responsive local weather application built with HTML, CSS, and JavaScript. The app uses the Open-Meteo API to display current weather conditions and a multi-day forecast without requiring an API key.

## Features

- Search for weather by city or town
- Current temperature and weather conditions
- Apparent temperature, humidity, and wind speed
- Daily high and low temperatures
- Multi-day weather forecast
- Celsius and Fahrenheit unit switching
- Responsive mobile and desktop layout
- Automatic light and dark mode support
- Accessible search controls and keyboard navigation
- Fallback sample data when the weather API is unavailable

## Technologies

- HTML5
- CSS3
- JavaScript
- Open-Meteo Forecast API
- Open-Meteo Geocoding API
- Visual Studio Code
- GitHub Copilot
